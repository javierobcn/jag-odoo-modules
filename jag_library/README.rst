This module extends Odoo to manage a personal or business library,
treating books as products and adding specific entities for authors,
publishers, and genres.

It provides dedicated menus, security groups, book metadata, ISBN
validation, and integrations with contacts, stock locations, and website
blog publishing.

Usage
=====

1. Go to *Library* from the Odoo main apps menu.
2. Create or edit contacts and mark them as authors or publishers when
   needed.
3. Create books from the catalog and complete library-specific fields.
4. Organize genres from *Library > Book Genres*.
5. Use the ISBN verification action on book records when required.
